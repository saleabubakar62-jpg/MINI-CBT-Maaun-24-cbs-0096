# Mini CBT Web App

## What it does

## How to run

1. Install Flask:
   pip install flask

2. Run the app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000

## Features
- Multiple questions
- Score tracking
- Timestamp result
